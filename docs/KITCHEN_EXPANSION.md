# 廚房與雙人床

2026-10-23，使用者已確認本機預覽，授權連同陽台提交、推送與部署。延續陽台擴建，使用者要求下一個場景，並追加將臥室改為雙人床。

## 可體驗內容

廚房位於客廳右側、陽台下方，以有高度的隔板分區，從客廳前方門口進出。奶油色棋盤磁磚搭配木質料理檯、鼠尾草綠櫥櫃、烤箱、冰箱、水槽、食譜與早餐桌。

- **切切蔬菜**：抬刀與落刀分段進行，整根蔬菜逐漸縮短、切片逐片出現。
- **煮鍋暖湯**：原有手臂握住湯勺攪拌，湯面蔬菜與熱氣可見；離開時關閉爐火並放回湯勺。
- **烤餅乾**：轉動烤箱旋鈕後等候，餅乾逐漸金黃，完成後指示燈熄滅。

三個動作都可從廚房動作欄、數字鍵或對應家具觸發，也會自主發生並寫入生活日記。手動選房間只切換鏡頭；動作欄跟隨狐狸實際所在位置。早餐桌、冰箱與水槽目前為環境陳設，沒有額外的用餐、備料或洗碗互動。

料理檯前會先完成收手，再向後退開兩小步，最後轉身離開。使用現有連續手臂網格與固定肩膀接點，手與工具使用同一組世界座標目標。離開分頁或零時間更新時，料理、道具與熱氣均暫停。

雙人床從原本寬度 .85 加寬至 1.65，床墊、床頭板同步加寬並加入第二顆枕頭。臥室左側向外增加 .8，連同地板、牆面、牆頂與踢腳板延伸；靠走道的床緣維持原位，讓既有轉身、尾巴與上下床路線保有空間。
