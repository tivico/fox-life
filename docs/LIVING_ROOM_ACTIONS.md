# 客廳生活動作 · 2026-10-18

狀態：使用者於 2026-10-18 確認此版本並授權發布。沿用 main 分支的 GitHub Actions 測試、建置與 GitHub Pages 部署流程。

## 可以體驗的內容

| 動作 | 流程與表現 |
| --- | --- |
| 看電視 | 走到沙發前，先抬身、收尾巴，再坐到坐墊上；拿遙控器開啟原創風景小節目，偶爾歪頭；結束時操作遙控器關機、歸位，起身繼續生活。 |
| 窩沙發 | 坐下靠著沙發，手臂放鬆、瞇眼、輕晃腳，休息後再起身。 |
| 喝杯茶 | 到電視櫃拿杯，拿著杯子走到沙發，坐下喝三小口；起身後走回電視櫃，把杯子放回杯碟。中途接受新邀請也會先完成杯子歸位。 |
| 做運動 | 到客廳運動墊，分段抬臂、左右伸展、原地交替抬腳踏步，最後放鬆。取代主入口的玩毛線。 |
| 聽音樂 | 坐在沙發上，跟著節奏輕晃身體、點頭與晃腳；小音響亮燈、浮出音符。聲音開啟且音樂音量大於零時，播放原創短旋律。 |
| 整理沙發 | 走近沙發，伸手拍鬆抱枕、整理毯子；原有抱枕隨拍打輕動，最後擺正，毯子整理成較短的折疊形狀。 |

六種動作都有自主版本、玩家邀請、冷卻、可觀察的準備／進行／收尾階段，以及只在實際進入活動階段時寫入的日記。

## 房間與操作

- 臥室動作欄：看風景、睡個覺、讀本書、吃點心、掃掃地。
- 客廳動作欄：看電視、窩沙發、喝杯茶、做運動、聽音樂、整理沙發。
- 動作欄依狐狸的位置切換，數字快捷鍵對應當下可見順序。手動選臥室／客廳視角只改鏡頭。
- 房間面板有獨立「去客廳／回臥室」，也可邀請狐狸到手動查看的房間。
- 圓茶几已移除；電視與電視櫃搬到原茶几位置並正對沙發，客廳預設鏡頭可看到螢幕正面。茶杯與書放在電視櫃上，取杯通道保留。
- 電視／遙控器對應看電視；沙發對應休息；茶杯／杯碟對應喝茶；運動墊對應運動；音響對應聽音樂；抱枕／毯子對應整理。
- 一次完成一個玩家邀請。新的邀請可中斷自主活動，先安全收尾再開始；玩家活動仍拒絕重複及交叉邀請。
- 聲音沿用使用者手動開啟規則與音量設定。音響旋律受音樂音量控制，遙控器、杯子、喝茶及布料聲受音效音量控制。
- 背景分頁暫停角色、道具與片段進度，返回不補播聲音或追趕離線時間。

## 實作邊界

- `LivingActivity.ts`：六個客廳行為的時間、到達、坐下、拿杯／搬運／歸位與安全退出。
- `LivingVisual.ts`：在原角色骨架上疊加坐姿、伸展、踏步與道具，不以縮放四肢製造新動作。每幀先還原自己的疊加，避免姿勢累積。
- `livingRoom.ts`：電視、原創風景節目、音響、運動墊及家具命中目標；螢幕、停放道具與音符跟隨真實階段。
- `Character.ts`：接入移動、玩家邀請鎖定、自主選擇、冷卻及安全收尾。單房歷史預覽與舊版毛線行為保留供原有回歸使用；主入口不顯示、不自主觸發毛線。
- `LifePanel.ts`／`life.ts`：按實際房間切換按鈕、快捷鍵、近況、進度及日記。
- 沒有新增套件、外部影片、外部音樂、後端、帳號或狀態存檔；電視風景與短旋律皆由本專案程序產生。

## 驗證

- 移除茶几、搬動電視與調整鏡頭後，重新通過 17 項客廳／房間整合測試，以及 TypeScript 檢查與正式建置；包含新取杯位置的拿杯、歸還、中斷與家具避碰。
- 修正整理沙發時頭與手臂伸入坐墊的問題：縮短前傾距離，先抬手再伸手、收尾先後退再放手。坐姿略微抬高並讓腳往前，避免腳與休息時的尾巴陷入坐墊；幾何回歸檢查補入沙發底座、坐墊、抱枕與毯子。
- 角色自身穿模修正：整理時雙臂向外展開；運動抬手與側伸展共用向外展臂的軌跡；拿茶杯時尾巴降低抬起角度並向後留出空間，避免尾巴穿進頭與軀幹。
- 修正整理毯子使用房間座標而非沙發局部座標的問題，折疊後仍留在沙發上；家具避碰檢查改用每幀實際動畫位置。
- 全部 98 項測試通過；正式建置與 TypeScript 檢查通過。
- 新增 12 項客廳整合測試：六動作在 20／60／144 Hz 完整流程、跨房移動、時長、邀請排他、日記去重；每一個客廳動作安全切回五種臥室邀請；喝茶在拿杯、搬運、坐下、喝茶、起身、歸還與放杯七階段被打斷仍先放杯；房間動作切換；電視、遙控器、茶杯與音響同步；背景暫停；音效節點與生成音訊；坐墊位置、地板及硬家具幾何；六種家具命中、遮擋、拖曳與清理；三種影格率下整理／運動的前臂與頭部、拿杯時遠端尾巴與頭／軀幹的實際網格內部穿透檢查（保留肩膀與尾根的接合）。
- 既有房間測試更新為運動取代毛線；保留原單房所有行為、道具、路徑與音訊回歸。
- 原本表情測試加入新 Living 狀態，持續驗證所有表情片段的切換、數值範圍與背景暫停。
- 正式建置含 TypeScript；既有共享 JavaScript chunk 超過 500 kB 的提醒仍存在。本輪不宣稱完成獨立 Chrome FPS 驗收。
- In-app Browser 實際操作客廳家具邀請、房間動作欄切換、看電視與運動、由看電視安全切換喝茶並放杯；檢查桌面與 390×844 版面。最終瀏覽器 error 記錄為空，預覽恢復跟隨狐狸模式。
