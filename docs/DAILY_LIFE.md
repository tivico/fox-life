# 更多生活細節 — 2026-10-17

依使用者指定加入打掃、玩耍、閱讀打瞌睡與伸懶腰。此次範圍是程序動作、實際道具、中文近況、玩家邀請與日記；不加入 Needs、Inventory 或離線模擬。

- 打掃：走到床前取掃帚、帶到地毯，單手短幅掃動並抬起回收，結束後帶回原位放好。
- 玩耍：走到活動區、撥弄毛線球、追看球的移動、收好並回日常。
- 閱讀小事件：部分閱讀過程會閉眼點頭，書保持在手上，再醒過來繼續讀。不是每次都發生。
- 伸懶腰：睡醒後先離開床邊，到活動區伸懶腰；平日偶爾也會在散步後發生。
- 兩個新行為都能自主發生，並可由按鈕／快捷鍵邀請；沿用單一玩家指令鎖與安全退出。
- 實際進入新行為與小事件才新增日記，閱讀打瞌睡不重複新增閱讀紀錄。

既有 `eatLayout` 保留四家具基準；實際主頁使用加入活動區的 `homeLayout`。此選擇使已接受的四家具驗證仍可單獨回歸，新完整生活則以新的整合測試驗證。Character 擁有世界位置、選擇與計時，visual 只處理局部姿勢與道具。

## 操作

下方新增「掃掃地」／`5` 與「玩毛線」／`6`。也能點床前的掃帚或書架上的毛線球。打瞌睡與伸懶腰是情境小事件，沒有獨立的催促按鈕；可以邀請閱讀或睡覺，再看牠自然接續。所有行為結束後回自主生活。

## 實作

- `daily.ts` 定義兩個新行為與伸懶腰的實際時長／收勢；兩個新自主候選各一格，沿用 Walk 權重與連走上限，各有獨立 cooldown。
- `dailyVisual.ts` 管理局部姿勢、毛線球與打瞌睡 Z；`cleaning.ts` 處理掃帚、地面灰塵與單手掃地。局部姿勢在下一幀先還原，再套用原有動畫，避免頭／手／尾巴 offset 累積。
- Clean 使用 approach → settle → carry → active → return → finish，先取用、搬運，打掃結束或被替換時先放回掃帚，再開始唯一的新邀請。Play 沿用 approach → settle → active → finish。
- 掃地保留原本單一圓潤手臂與手掌，僅旋轉右肩；不替換手型、不拉伸手臂，也不添加分節手臂。掃帚柄跟隨右手接觸點，左手自然垂放。三次短掃之間抬起刷頭回收，只有刷頭接地推掃時出現灰塵。
- 床前與手上使用同一份掃帚幾何、相同世界比例；拿起時隱藏原位掃帚，放回再恢復，避免同時出現兩把或縮放生成。攜帶時抬高，避開房間前緣。
- 部分 Read 中段用閉眼、點頭、書頁停頓與 Z 演出打瞌睡，結束後繼續讀；被打斷時與書一起收勢。
- 完整 Wake 結束後，先走回活動範圍，再伸懶腰。小事件結束或中途邀請會恢復正常姿勢。
- 日記分開追蹤主要行為與小事件，Doze → Reading 不會再新增一則 Bookshelf。既有日記資料相容，仍保留最近 40 則。
- 六個邀請在桌面排列一列，窄螢幕排列兩列。Debug 顯示真實 activity kind／phase／elapsed、兩個 cooldown 與 micro-event。
