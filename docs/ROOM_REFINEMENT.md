# 小屋居家細節 — 2026-10-17

依使用者對空曠房間的回饋，將現有小屋補成可辨識的睡眠角、閱讀角、餐桌與窗邊收藏角。沿用 PRODUCT.md 的柔和消光、微縮住宅與少量撿拾物方向。

## 已實作

- 木紋拼接地板、織紋與幾何圖案地毯、綠色拼布床單。
- 低牆護板與收邊、亞麻窗簾、窗外山景與陽光。
- 床頭圓桌、暖色檯燈與局部光源、兩株不同大小的盆栽。
- 收藏櫃、壓葉小畫、鈕扣小盤、疊放的書、編織收納籃。
- 餐桌陶杯；點杯、杯碟或把手，與原本餐桌共用 Eat 邀請。

新物件以固定位置佈置，尚不支援玩家搬動、更換或收集。燈、植物、收藏品為裝飾，沒有額外行為。窗外景色是靜態美術，不是天氣或日夜系統。

## 實作與界線

`src/roomDetails.ts` 產生共享材質與幾何裝飾；四張純資料紋理使用 DataTexture 生成，可直接在 Node 的場景測試中載入，沒有遠端素材與新套件。紋理只改變原床墊／地毯／地板／窗戶材質，保留床面接觸高度與四個互動站位。主頁與兩個模型預覽頁的清理流程均釋放新增紋理。

保留中央活動區。空間測試曾找出籃緣及左牆飾條與尾巴空間重疊，已將籃子後移、飾條收回牆體內。未縮小角色包圍、移除碰撞檢查或改動 Character 動作來通過測試。

## 驗證

- TypeScript、production build 通過；既有 >500 kB shared chunk 提醒仍保留。
- 最終 47 項 Node 測試通過，含 Sleep 接觸、Read／Eat 路徑、跨行為安全退出與四種 raycast 回歸。
- In-app Browser 檢查新房間構圖與邀請操作；保留 screenshot 於 `docs/evidence/room-refinement/`。
- 尚未完成獨立 Chrome 效能驗收；新增細節不代表已達成 60 FPS。

本輪不變更既有 PO Acceptance 狀態。房間自由環繞時，家具與牆邊仍可能遮住角色；可調整視角觀看。
