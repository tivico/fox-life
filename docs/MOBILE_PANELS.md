# 手機精簡介面 — 2026-10-27

使用者回饋手機功能列表遮住太多場景，本輪調整角色、房間與動作欄。使用者已授權提交並推送；推送至 main 會觸發既有 GitHub Pages 部署流程。

- 寬度不超過 650px 或高度不超過 500px 時使用精簡布局。房間收合後只留一排角色切換與展開按鈕；底下只留目前近況、進度與「動作」按鈕。
- 動作展開為可捲動的列表，保留所有單人與雙人邀請。接受邀請後自動收起；拒絕時保留列表與回饋。房間視角、角色切換或成功前往房間後也收起房間資訊。
- 小螢幕上房間與動作面板互斥展開。直橫向切換依布局套用偏好；桌機既有的房間展開設定不再讓首次手機瀏覽自動展開。
- 按鈕有展開狀態、控制區域名稱與至少 44px 點擊高度。隱藏內容不進入鍵盤巡覽；收合時若焦點在內容裡，會移回展開按鈕，並支援 Esc 收合。關閉日記等對話框不會順帶收合面板。
- 精簡布局將場景回到畫面中央；開合面板不移動鏡頭。保留「靜靜陪伴」供全畫面觀看，提示訊息跟著動作欄的位置，避免沿用舊版固定底距。
