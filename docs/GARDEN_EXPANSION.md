# 陽台小花園

2026-10-23：在臥室右側新增第一個戶外空間。使用者已確認本機預覽，授權連同廚房與雙人床提交、推送與部署。

## 本輪完成

陽台從臥室東側玻璃門進出，地板保持同高；側邊有欄杆，前側沿用剖面小屋的低邊緣。木平台上配置淡色花圃、小花盆、蝴蝶、掛水壺的木架與長椅。原有臥室及客廳仍可往返。

| 互動 | 實際流程 |
| --- | --- |
| 澆澆花 | 走到花圃，雙手拿起掛架上的水壺，分三次傾壺澆花，再放回原位。水滴從實際壺嘴開始，落到花圃。 |
| 看蝴蝶 | 走到小花盆旁，抬頭、輕輕轉頭看蝴蝶。蝴蝶平時也會飛動。 |
| 坐著吹風 | 走到長椅前，抬身坐到椅面，尾巴移向身側，輕晃雙腳，休息後回到站姿。 |

可使用下方動作欄、數字鍵 1～3，或直接點花圃／水壺、蝴蝶花盆、長椅。邀請仍一次一個；自主動作被打斷時會先放回水壺或起身。日記只記錄實際進入活動階段的片段。

房間面板新增「陽台花園」及前往按鈕。「跟隨狐狸」在穿過房門時平順轉移焦點；手動選房間只改鏡頭，動作欄仍依狐狸位置切換。「全屋」能查看三個空間。手機版使用五個視角選項及三個花園動作，不需橫向捲動。

## 本機檢查

執行 `npm run dev -- --port 5173 --strictPort`，開啟 [主畫面](http://127.0.0.1:5173/)，按「去陽台花園」，到達後試三個新動作。也可先固定陽台視角，再邀請狐狸前往。

[陽台動作檢查頁](http://127.0.0.1:5173/tools/garden-review.html) 可暫停實際動畫，在準備、進行、收尾的指定時間切換正面／側面／上方檢查。這個工具只由開發伺服器提供，不在正式建置入口中。

`tests/garden.test.mjs` 新增 9 項測試，涵蓋：

- 三個房間的六種往返方向，20／60／144 Hz 下都從門口走過、不瞬移。
- 三種動作的計時、單一邀請鎖定、日記、拿壺／放壺，以及各階段安全中斷。
- 原有肩膀接合及手臂長度；手臂避開頭部，尾巴避開頭部與身體。
- 實際姿勢對地板、花圃、長椅、門框、欄杆的網格碰撞，坐下時椅面支撐身體。
- 花園家具點擊、拖曳／遮擋排除，以及隱藏水壺不攔截點擊。
- 跟隨／固定鏡頭、減少動態效果、零時間暫停，以及十分鐘自主生活。

既有 100 項測試與新增 9 項均通過；`npm run build -- --base=/fox-life/` 通過 TypeScript 與正式建置。Three.js 共用資源仍有超過 500 kB 的既有建置提示。瀏覽器已檢查桌面與 390×844 手機版；本輪未重新進行獨立 Chrome 的效能驗收。

檢查畫面保存在 [桌面陽台](evidence/garden-expansion/balcony-desktop.jpg)、[手機陽台](evidence/garden-expansion/balcony-mobile.jpg)、[澆花側面](evidence/garden-expansion/watering-side.jpg)、[長椅側面](evidence/garden-expansion/bench-side.jpg) 與 [看蝴蝶](evidence/garden-expansion/butterfly-side.jpg)。

## 後續逐步擴建方向

每次完成一個空間及其專屬互動，先讓使用者在本機確認，再發布。

| 順序 | 空間方向 | 可搭配的生活動作 |
| --- | --- | --- |
| 1（本輪） | 陽台小花園 | 澆花、看蝴蝶、坐著吹風 |
| 2（已加入本機預覽） | 廚房／餐區 | 切菜、煮湯、烤餅乾，見 [廚房擴建](KITCHEN_EXPANSION.md) |
| 3 | 書房／手作角 | 畫畫、寫字、做小物 |
| 4 | 浴室／洗衣區 | 洗手、刷牙、晾衣服 |

後續房間的位置、家具與動作細節再逐間討論；本輪沒有加入新的需求值、種植成長、天氣或存檔系統，也沒有新增套件。
