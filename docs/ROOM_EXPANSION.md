# 臥室與客廳 · 2026-10-18

> 此頁記錄兩房擴建初版。後續依使用者要求，主入口玩毛線已改為運動，並加入電視等六種客廳生活動作與房間專屬動作欄；最新操作見 [客廳生活動作](LIVING_ROOM_ACTIONS.md)。

依使用者「這是臥室，開始可以有客廳」及「換到另一個空間需要聚焦」的方向，將主入口擴充為相連的兩房小家。

## 體驗

- 原有臥室保留床、窗戶、書架、餐桌與掃帚。新增的客廳有沙發、抱枕、毯子、茶几、地毯、落地燈、邊櫃與植栽。
- 兩房由中央開口相連。狐狸會自行選擇兩房內的散步目的地；玩毛線的實際演出與可點毛線移至客廳。
- 點客廳沙發、茶几或「邀請牠來客廳」：狐狸先安全退出當前自主活動，經門口到客廳觀望四秒，再繼續生活。房間面板也可邀請返回臥室。
- 家具邀請沿用一次一個玩家指令、不排隊、不覆寫的規則。看窗外、睡覺、閱讀、吃點心與打掃都能從客廳開始，經門口回臥室完成。
- 預設鏡頭跟隨狐狸所在房間，跨過門口中線時平順切換構圖。手動選臥室／客廳固定視角；「跟隨狐狸」恢復自動聚焦；「全屋」查看兩個空間。
- 選視角只改鏡頭，「邀請牠來」才送出角色指令。拖曳鏡頭會停止尚未結束的相機移動；重設視角恢復當前模式的構圖。系統偏好減少動態時直接完成鏡頭切換。
- 日記依實際到達的房間寫入，不將房間停留誤記為看窗外。關閉頁面後仍不產生離線進度。

## 實作

- `HomeNavigation.ts`：兩房的活動區、房間歸屬與通過門口的中繼點。
- `Character.ts`：可選的相連房間路徑、房間邀請與既有安全退出；沿用原移動、轉向及背景計時。
- `livingRoom.ts`：客廳家具與原創程序織紋。保留中央活動區及門口淨空。
- `HomeView.ts`／`RoomPanel.ts`：鏡頭跟隨、固定房間、全屋與到訪邀請。
- `scene.ts`：主入口使用 `createScene({ expanded: true })` 與 `expandedHomeLayout`。預設 `createScene()` 及原有 layout 保留，讓歷史造型預覽與既有單房幾何測試維持可用。
- `life.ts`：房間停留日記；`SoundCues.ts`：客廳地毯腳步。聲音左右定位相對鏡頭焦點計算，避免換房後全部偏向單側。

## 驗證與範圍

- 原有 78 項測試及新增 8 項測試通過；新增測試涵蓋 20／60／144 Hz 到訪、六種跨房邀請、安全退出與掃帚歸位、角色與毛線對新家具／門框的幾何避讓、十分鐘自主生活、鏡頭模式、單一毛線與門口淨空、地毯腳步及零 delta 暫停。
- TypeScript／正式建置通過，仍有既有共享 JavaScript chunk 超過 500 kB 提醒。
- In-app Browser 檢查 1280×720 與 390×844 版面，觀察自主跨房跟拍、客廳聚焦、手動查看臥室及回臥室邀請。此輪未做獨立 Chrome FPS 量測。
- 客廳目前支援到訪觀望、散步與玩毛線；沙發坐下、看電視、廚房、浴室及家具自由布置留待後續增加。
- 沒有新增套件、帳號、後端、Needs、遊戲狀態存檔或離線模擬。本輪不更改歷史 PO Acceptance 結論。
